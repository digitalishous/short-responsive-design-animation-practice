# short-responsive-design-animation-practice
1 page design in HTML/CSS with only a title, 4 img cards and small animated hearts.
The purpose of this design is to apply responsive design shorthand solutions as well as pure CSS animation in a clean and simple manner. 
I've downloaded free dog images from pexels.com, and I've edited them in Canva (used Slate Mono filter to make them black/white). Downloaded the images from Canva as PNGs with transparent background (pro option) 500px by 500px.
